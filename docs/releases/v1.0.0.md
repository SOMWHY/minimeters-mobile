# MiniMeters Mobile 1.0.0

First public release. The phone is a wireless second screen for the MiniMeters plugin: the desktop
streams audio analysis over your local network, the phone draws it with Skia.

## What's in it

- **Six meters**: waveform, spectrum, spectrogram, VU, LUFS (momentary / short-term / integrated),
  oscilloscope.
- **Editable dashboard grid**: drag modules between cells, phone uses a 2-column grid and tablets a
  4-column one, and the layout survives rotation and app restarts.
- **Two-step pairing**: scan the QR code from the plugin window, or type the address and token by
  hand (host only, `ws://host:port/ws`, IPv6 literal, or the whole QR payload pasted in). Pairing
  issues a device token, so later launches reconnect without the QR.
- **Fullscreen mode**: a settings toggle hides the status and navigation bars for a clean
  dashboard; the edge swipe still reveals them.
- **Auto-update notices**: the app checks for a new version on launch and only downloads when you
  tap the notice.

## Requirements

| | |
| --- | --- |
| Phone | Android 8.0+, **arm64 only** |
| Desktop | Windows with the MiniMeters plugin (`vst3` / `clap`) or the standalone build |
| Network | Phone and computer on the same local network; desktop reachable on TCP **8422** |
| Firewall | Must allow inbound TCP 8422 on the desktop — otherwise the plugin window shows `Network: unavailable` on the phone side |

## Install

1. Download `minimeters-mobile-1.0.0-arm64.apk` and `SHA256SUMS.txt` below.
2. Verify (optional, recommended):
   ```powershell
   certutil -hashfile minimeters-mobile-1.0.0-arm64.apk SHA256
   ```
3. Install. Android warns about an **unknown source** and **Play Protect not having scanned** the
   app — both are expected, this build is not distributed through Google Play. Allow the install
   and pick "install anyway".
4. Open the app, then scan the QR code shown in the plugin or in the standalone window.

## Privacy

Audio is streamed over your local network only and is never stored or uploaded. The app has no
account, no analytics and no advertising. Full text: [`PRIVACY.md`](../../PRIVACY.md).

## Notes

- The APK is signed with a key held in EAS. Updates install over the previous version as long as
  the signature stays the same.
- iOS and HarmonyOS are not part of this release. HarmonyOS 4.x can install the APK once
  纯净模式 is turned off; HarmonyOS NEXT 5.0+ cannot run APKs at all.
