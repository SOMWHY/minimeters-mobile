# MiniMeters Mobile 1.0.1

Two changes, both visible the moment you open the app: the launcher icon is the gauge mark now
instead of the Expo template, and the interface speaks Chinese.

## What's new

- **Real app identity.** The launcher icon, the adaptive icon layers and the splash screen are all
  derived from one source mark: an orange gauge on charcoal. The splash no longer flashes template
  blue before the dashboard appears.
- **Chinese interface.** Settings, the pairing flow and the update notice are translated, and the
  language switch lives in the settings panel. English is still there; the app starts in Chinese.
- **Settings button on the right edge.** The orb now sits vertically centred on the right instead of
  the bottom-right corner, so it no longer competes with the bottom row of meters. Existing saved
  positions are migrated rather than reset.

## Requirements

| | |
| --- | --- |
| Phone | Android 8.0+, **arm64 only** |
| Desktop | Windows with the MiniMeters plugin (`vst3` / `clap`) or the standalone build |
| Network | Phone and computer on the same local network; desktop reachable on TCP **8422** |
| Firewall | Must allow inbound TCP 8422 on the desktop — otherwise the plugin window shows `Network: unavailable` on the phone side |

## Install

1. Download `minimeters-mobile-1.0.1-arm64.apk` and `SHA256SUMS.txt` below.
2. Verify (optional, recommended):
   ```powershell
   certutil -hashfile minimeters-mobile-1.0.1-arm64.apk SHA256
   ```
3. Install over 1.0.0 — the signature is unchanged, so it updates in place. Android may warn about
   an **unknown source** and **Play Protect not having scanned** the app; both are expected, this
   build is not distributed through Google Play.
4. **The icon is a native resource, so it cannot arrive over the air.** If the launcher still shows
   the old icon after installing, the launcher is caching it: uninstall first, or restart the phone.

## Upgrading from 1.0.0

`runtimeVersion` follows the app version, so 1.0.0 installs stop receiving over-the-air updates at
the moment 1.0.1 is published. Install 1.0.1 to stay on the update channel — nothing else about the
app changes, pairing details and dashboard layout carry over.

## Privacy

Audio is streamed over your local network only and is never stored or uploaded. The app has no
account, no analytics and no advertising. Full text: [`PRIVACY.md`](../../PRIVACY.md).

## Notes

- The APK is signed with a key held in EAS. Updates install over the previous version as long as
  the signature stays the same.
- iOS and HarmonyOS are not part of this release. HarmonyOS 4.x can install the APK once
  纯净模式 is turned off; HarmonyOS NEXT 5.0+ cannot run APKs at all.
